# Beechcraft-Bonanza-Weight-Balance-Calculator
Educational Beechcraft Bonanza A36 Weight &amp; Balance calculator developed in LabVIEW. NOT approved for real-world flight operations or dispatch use. Please read the README and disclaimer before using the software.

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

⚠️ Disclaimer ⚠️

This project is an educational Weight & Balance calculator developed for the Beechcraft Bonanza A36 aircraft. The calculations, limits, and CG envelope used in this application are based on the aircraft data and documentation provided in the Beechcraft Bonanza A36 Pilot’s Operating Handbook and Flight Manual.

This software is intended solely for educational, academic, and demonstration purposes. It must NOT be used for real-world flight planning, operational decision-making, dispatching, or any form of actual aviation operation.

///////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

LabVIEW (Laboratory Virtual Instrument Engineering Workbench) is a graphical programming environment developed by National Instruments for engineering, automation, simulation, data acquisition, and control system applications.

This application was developed using LabVIEW graphical programming structures and components such as arrays, DBL numeric values, indicators, controls, buttons, Boolean logic, real-time graphs, Build Array, Bundle/Unbundle structures, arithmetic operation blocks, comparison blocks, loops, and case structures.
